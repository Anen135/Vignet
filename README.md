# Vignet

Расширение Chrome/Opera для визуальных эффектов на `chatgpt.com`, управляемое через MCP. Сервер работает на вашем компьютере:

```text
ChatGPT → HTTPS туннель → HTTP MCP Bridge → локальный WebSocket → расширение
```

Быстрая установка и запуск:

```powershell
npm run setup
```

Выберите **1 — Настроить всё**, затем **2 — Запустить Bridge и туннель**. При настройке доступны **режим 1 — Cloudflare** и **режим 3 — ngrok**. Для ngrok укажите закреплённый dev domain из Dashboard → Domains: launcher передаёт его через `--url` и не заменяет случайным адресом. Меню собирает расширение и находит клиент в папке проекта, распакованном каталоге или PATH. Для ngrok заранее установите клиент и сохраните authtoken в стандартной конфигурации ngrok либо задайте `NGROK_AUTHTOKEN`. Если зависимостей проекта нет, меню установит их. Ключ OpenAI и Secure MCP Tunnel больше не используются.

В ChatGPT укажите показанный публичный URL с `/mcp`, выберите **OAuth** и оставьте поля Client ID / Secret пустыми для автоматической регистрации. На странице подключения и в терминале появится одинаковый код: сверьте его и введите в терминале «да».

Quick Tunnel выдаёт случайный адрес при каждом запуске. Старый `https://prevention-highways-algorithm-ing.trycloudflare.com/mcp` можно использовать только пока соответствующий туннель продолжает работать и направлен на этот Bridge. Зарезервировать его нельзя. Для постоянного URL выберите **пункт 5 → режим 3 — ngrok**: меню запускает ngrok вместе с Bridge, определяет URL и останавливает оба процесса при выходе. Прямой запуск — `npm run start:ngrok`. Существующий Cloudflare Tunnel со своим доменом или Tailscale Funnel можно подключить через **пункт 5 → режим 2**.

Расширение загружается из **`dist/extension`**, пакеты эффектов — из `dist/packages/`. Требуются Node.js 20+ и Chromium 135+ для JavaScript-эффектов.

Инструкции: [SETUP.md](SETUP.md). Формат пакетов: [ASSET_SPEC.md](ASSET_SPEC.md). Границы доверия: [SECURITY.md](SECURITY.md).

Проверки:

```powershell
npm run build
```
